Staff Accounts

Disable a departing staff member's account first if there's any chance you'll need their history intact — reports, receipts, and the audit log all still show their name. Delete only once you're sure: it permanently removes the account (their past records stay on file, but can no longer be edited via that account).

Database Backups

Backups run automatically once a day and are kept for 30 days — but they're saved on this same computer. If this PC's disk fails, the backups folder is lost with it. Download a copy periodically and save it to a USB drive, another computer, or cloud storage — that's the only thing that protects you if this machine itself is lost, stolen, or damaged.
